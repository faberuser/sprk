# Build-time restoration sources

These JSON files are embedded in DllPatcher for older, unbaked clients and are
also independent regression fixtures for restored recipes. The running server
does not read them. Baked clients validate their native data manifests before
the patcher removes restoration payloads and data hooks from the game assembly.

The effective server values formerly supplied by these files are now stored in
`tables/InventorySupport.json`, `tables/HeroShopSupport.json`,
`tables/ArenaGuildSupport.json`, and `tables/BattleSupport.json`. These support
tables remain authoritative for server validation, prices, and rewards. Keep
their baked values when regenerating server data; copying an older raw export
over them would discard the corrections. Conquest's recurring calendar is
generated by the server from its baked session template.

`ChatCommon.png` and `ChatCommon.json` preserve the Common texture and UIAtlas
sprite rectangles/borders from the Pre-Doomsday Android archive:
`com.vespainteractive.KingsRaid/files/Documents/Patch/Android/Assetbundle/HighAndMidSpec/NguiAtlas_UI_Prefab_Common.unity3d`.
They were extracted with UnityPy 1.25.3 (Texture2D.image and UIAtlas mSprites).
SprkAccounts embeds these resources and applies the atlas only to chat-window
Common sprites. Texture and metadata must stay paired: the current client uses
different sprite coordinates. The original UISprites and UIToggle wiring remain.
Run `python scripts/tests/account-ui/check.py` for native-prefab regression checks;
it needs a graphics device to verify Unity material textures (no -nographics).

Chat window and component selection now use an explicit battle check, so startup
before LobbyManagement exists defaults to the full lobby layout. Preserve its
native Normal depth, header/back observers, anchors and background hierarchy.
Do not clone the full-screen backdrop into the Topmost battle overlay: that
covers the lobby header and uses the wrong tab geometry. Check layout changes
in a running client; isolated sprite renders omit the shared lobby header.
