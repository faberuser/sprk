# Build-time restoration sources

These JSON files are embedded in DllPatcher for older, unbaked clients and are
also independent regression fixtures for restored recipes. The running server
does not read them. Baked clients validate their native data manifests before
the patcher removes restoration payloads and data hooks from the game assembly.

The effective server values formerly supplied by these files are now stored in
`tables/InventorySupport.json`, `tables/HeroShopSupport.json`,
`tables/ArenaGuildSupport.json`, and `tables/BattleSupport.json`. These support
tables remain authoritative for server validation, prices, and rewards. Keep
their baked values when regenerating server data; copying an older raw export
over them would discard the corrections. Conquest's recurring calendar is
generated by the server from its baked session template.
